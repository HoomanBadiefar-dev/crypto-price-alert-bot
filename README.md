# ربات هشدار قیمت کریپتو — HGC Academy

ربات تلگرامی برای هشدار قیمت ارزهای دیجیتال و مجموعه‌ای از ابزارهای کاربردی معامله‌گری، که به‌صورت کاملاً رایگان روی **GitHub Actions** اجرا می‌شه (بدون نیاز به خرید سرور).

---

## 📁 ساختار فایل‌ها

| فایل | توضیح |
|---|---|
| `bot.py` | کد اصلی ربات — پردازش دستورات، هشدارها، ابزارها |
| `top20_report.py` | اسکریپت مستقل برای ارسال گزارش ۲۰ ارز برتر |
| `requirements.txt` | کتابخونه‌های پایتون مورد نیاز |
| `alerts.json` | لیست هشدارهای ثبت‌شده (خودکار به‌روزرسانی می‌شه) |
| `state.json` | آخرین پیام پردازش‌شده‌ی تلگرام (برای جلوگیری از پردازش تکراری) |
| `.github/workflows/check-prices.yml` | زمان‌بندی اجرای `bot.py` — هر ۵ دقیقه |
| `.github/workflows/top20-report.yml` | زمان‌بندی اجرای `top20_report.py` — هر ۴ ساعت |

---

## ⚙️ نحوه‌ی کار (معماری)

این ربات **Webhook یا سرور دائمی نداره**. به‌جاش:

1. GitHub Actions هر ۵ دقیقه یک‌بار `bot.py` رو اجرا می‌کنه
2. اسکریپت پیام‌های جدید تلگرام رو می‌خونه (`getUpdates`)، دستورات رو پردازش می‌کنه، و قیمت‌های هشدارهای فعال رو چک می‌کنه
3. تغییرات (هشدار جدید، هشدار فعال‌شده، ...) روی فایل‌های `alerts.json` و `state.json` ذخیره و مستقیم در ریپازیتوری commit می‌شه
4. هر ۴ ساعت هم `top20_report.py` جدا اجرا می‌شه و گزارش ۲۰ ارز برتر رو می‌فرسته

**⚠️ نکته‌ی مهم:** چون پردازش هر ۵ دقیقه یک‌بار انجام می‌شه، دستورات **فوری** جواب داده نمی‌شن — ممکنه تا ۵ دقیقه طول بکشه. برای پاسخ لحظه‌ای، باید معماری به سمت Webhook + هاستینگ دائمی (مثل Render) تغییر کنه.

## 🤖 دستورات ربات

| دستور | توضیح | مثال |
|---|---|---|
| `/start` | نمایش راهنما و دکمه‌های شیشه‌ای | `/start` |
| `/alert SYMBOL PRICE` | ثبت هشدار قیمت (جهت خودکار تشخیص داده می‌شه) | `/alert BTC 70000` |
| `/list` | لیست هشدارها با وضعیت و تاریخ ثبت | `/list` |
| `/risk BALANCE RISK% ENTRY STOP` | محاسبه‌ی حجم پوزیشن بر اساس ریسک | `/risk 1000 2 65000 64000` |
| `/gainers` | ۵ صعودی و ۵ نزولی برتر ۲۴ ساعته | `/gainers` |
| `/feargreed` | شاخص ترس و طمع بازار | `/feargreed` |
| `/convert AMOUNT FROM TO` | تبدیل بین ارزها | `/convert 100 USD BTC` |
| `/compare SYMBOL` | مقایسه‌ی قیمت بین چند صرافی (Binance, Coinbase, Kraken) | `/compare BTC` |
| `/export` | دریافت فایل پشتیبان کامل هشدارها | `/export` |

### نمادهای پشتیبانی‌شده
```
BTC, ETH, SOL, BNB, XRP, ADA, DOGE, TON, TRX, AVAX, LINK, DOT, MATIC, LTC, SHIB
```
(برای اضافه کردن نماد جدید، باید در دیکشنری `SYMBOL_TO_ID` داخل `bot.py` اضافه بشه — شناسه‌ی هر ارز رو می‌شه از سایت coingecko.com پیدا کرد.)

## 🔑 تنظیمات مورد نیاز (Secrets)

توی مسیر **Settings → Secrets and variables → Actions** این دو مقدار باید تنظیم بشن:

| نام Secret | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات که از BotFather گرفته می‌شه |
| `TELEGRAM_CHAT_ID` | آیدی چت مقصد پیام‌ها (از طریق `getUpdates` قابل پیدا کردنه) |

همچنین باید در **Settings → Actions → General → Workflow permissions** گزینه‌ی **Read and write permissions** فعال باشه، چون ربات نیاز داره فایل‌های `alerts.json` و `state.json` رو خودش commit کنه.

## 🧩 منابع داده

- **قیمت لحظه‌ای و لیست بازار:** [CoinGecko API](https://www.coingecko.com/en/api) — رایگان، بدون نیاز به کلید
- **شاخص ترس و طمع:** [Alternative.me API](https://alternative.me/crypto/fear-and-greed-index/) — رایگان، بدون نیاز به کلید
- **مقایسه‌ی صرافی‌ها:** Binance، Coinbase، Kraken (هرکدوم API عمومی رایگان دارن)

---

## 🚀 مسیر توسعه‌ی آینده

اگه در آینده نیاز به پاسخ **لحظه‌ای** (بدون تاخیر ۵ دقیقه‌ای) بود، پیشنهاد می‌شه:
1. ربات از مدل Polling (GitHub Actions) به مدل **Webhook** منتقل بشه
2. روی یه سرویس همیشه‌روشن مثل **Render**، **Railway**، یا **Fly.io** میزبانی بشه
3. `alerts.json` و `state.json` به یه دیتابیس سبک (مثل SQLite یا Redis) منتقل بشن تا نیازی به commit مداوم روی گیت‌هاب نباشه

## 📝 محدودیت‌های فعلی

- تاخیر تا ۵ دقیقه در پاسخ به دستورات و هشدارها
- فقط ۱۵ نماد از پیش تعریف‌شده پشتیبانی می‌شن (قابل گسترش)
- در `/compare`، Kraken فقط برای بخشی از نمادها پشتیبانی می‌شه
