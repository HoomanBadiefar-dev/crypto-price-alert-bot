# ربات هشدار قیمت کریپتو — HGC Academy

ربات تلگرامی برای هشدار قیمت ارزهای دیجیتال و مجموعه‌ای از ابزارهای کاربردی معامله‌گری، که به‌صورت کاملاً رایگان روی GitHub Actions اجرا می‌شود (بدون نیاز به خرید سرور).

---

## 📁 ساختار فایل‌ها

| فایل | توضیح |
|---|---|
| `bot.py` | کد اصلی ربات — پردازش دستورات، هشدارها، ابزارها |
| `top20_report.py` | اسکریپت مستقل برای ارسال گزارش ۲۰ ارز برتر |
| `requirements.txt` | کتابخانه‌های پایتون مورد نیاز |
| `alerts.json` | لیست هشدارهای ثبت‌شده — خودکار به‌روزرسانی می‌شود |
| `state.json` | آخرین پیام پردازش‌شده‌ی تلگرام — برای جلوگیری از پردازش تکراری |
| `.github/workflows/check-prices.yml` | زمان‌بندی اجرای bot.py، هر ۵ دقیقه |
| `.github/workflows/top20-report.yml` | زمان‌بندی اجرای top20_report.py، هر ۴ ساعت |

---

## ⚙️ نحوه‌ی کار (معماری)

این ربات سرور دائمی یا Webhook ندارد. به‌جایش:

1. GitHub Actions هر ۵ دقیقه یک‌بار bot.py را اجرا می‌کند.
2. اسکریپت با فراخوانی getUpdates، پیام‌های جدید تلگرام را می‌خواند. سپس دستورات را پردازش می‌کند و قیمت هشدارهای فعال را چک می‌کند.
3. هر تغییری — هشدار جدید، فعال‌شدن هشدار، و غیره — روی دو فایل ذخیره می‌شود: alerts.json و state.json. این دو فایل مستقیماً در ریپازیتوری commit می‌شوند.
4. top20_report.py هر ۴ ساعت یک‌بار، جدا از bot.py، اجرا می‌شود و گزارش ۲۰ ارز برتر را ارسال می‌کند.

نکته‌ی مهم: چون پردازش هر ۵ دقیقه یک‌بار انجام می‌شود، پاسخ دستورات فوری نیست — ممکن است تا ۵ دقیقه طول بکشد. برای پاسخ لحظه‌ای، باید معماری به Webhook همراه با هاستینگ دائمی (مثل Render) تغییر کند.

## 🤖 دستورات ربات

| دستور | توضیح | مثال |
|---|---|---|
| `/start` | نمایش راهنما و دکمه‌های شیشه‌ای | `/start` |
| `/alert SYMBOL PRICE` | ثبت هشدار قیمت؛ جهت به‌صورت خودکار تشخیص داده می‌شود | `/alert BTC 70000` |
| `/list` | لیست هشدارها همراه با وضعیت و تاریخ ثبت | `/list` |
| `/risk BALANCE RISK% ENTRY STOP` | محاسبه‌ی حجم پوزیشن بر اساس ریسک | `/risk 1000 2 65000 64000` |
| `/gainers` | پنج صعودی و پنج نزولی برتر ۲۴ ساعته | `/gainers` |
| `/feargreed` | شاخص ترس و طمع بازار | `/feargreed` |
| `/convert AMOUNT FROM TO` | تبدیل بین ارزها | `/convert 100 USD BTC` |
| `/compare SYMBOL` | مقایسه‌ی قیمت بین چند صرافی | `/compare BTC` |
| `/export` | دریافت فایل پشتیبان کامل هشدارها | `/export` |

نمادهای پشتیبانی‌شده:
BTC, ETH, SOL, BNB, XRP, ADA, DOGE, TON, TRX, AVAX, LINK, DOT, MATIC, LTC, SHIB

برای اضافه کردن نماد جدید، باید دیکشنری SYMBOL_TO_ID داخل bot.py ویرایش شود. شناسه‌ی هر ارز را می‌توان از سایت coingecko.com پیدا کرد.

## 🔑 تنظیمات مورد نیاز

دو مقدار زیر باید در مسیر Settings، سپس Secrets and variables، سپس Actions تنظیم شوند:

| نام Secret | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات؛ از BotFather دریافت می‌شود |
| `TELEGRAM_CHAT_ID` | آیدی چت مقصد پیام‌ها؛ از طریق getUpdates قابل پیدا کردن است |

همچنین باید در مسیر Settings، سپس Actions، سپس General، گزینه‌ی Read and write permissions فعال باشد، چون ربات نیاز دارد فایل‌های alerts.json و state.json را خودش commit کند.

## 🚀 مسیر توسعه‌ی آینده

اگر در آینده نیاز به پاسخ لحظه‌ای بدون تاخیر پنج‌دقیقه‌ای بود، پیشنهاد می‌شود:

1. ربات از مدل Polling روی GitHub Actions به مدل Webhook منتقل شود.
2. روی یک سرویس همیشه‌روشن مثل Render، Railway، یا Fly.io میزبانی شود.
3. فایل‌های alerts.json و state.json به یک دیتابیس سبک مثل SQLite یا Redis منتقل شوند، تا نیازی به commit مداوم روی گیت‌هاب نباشد.
